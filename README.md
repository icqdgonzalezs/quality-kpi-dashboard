# 📊 Panel de Control de KPIs de Calidad (Práctica)

Proyecto de práctica para simular el monitoreo de calidad en una línea de producción.  
Incluye extracción de datos, cálculo de KPIs industriales (tasa de defectos, Cp, Cpk, Pareto) y visualización en un dashboard interactivo con **Python**, **Streamlit** y **Plotly**.

## 🎯 Objetivo
Demostrar habilidades de análisis de datos aplicadas a control de calidad, partiendo de datos crudos simulados hasta un panel de monitoreo que facilita la toma de decisiones.

## 📈 KPIs calculados
- Tasa de defectos por lote y por tipo de defecto.
- Índices de capacidad de proceso (Cp, Cpk) para variables críticas (peso, longitud).
- Diagrama de Pareto para identificar los defectos más frecuentes.
- Evolución temporal de la tasa de defectos.
- Alertas automáticas cuando un KPI supera el límite de control.

## 🛠️ Tecnologías utilizadas
- Python 3.10+
- Pandas, NumPy
- Matplotlib, Seaborn, Plotly Express
- Streamlit (dashboard interactivo)
- Jupyter Notebook (exploración)
- Git / GitHub
